# 📱 VPN 管理器 (VPN Manager)

因为手机里囤了太多 VPN 和加速器（高达 84 个！），每次找起来太乱，于是顺手开发了这个轻量级的管理工具。

## ✨ 功能特性
- 🚀 **一键直达**：点击列表直接启动应用。
- 🎯 **智能识别**：通过权限与关键词，精准抓取 VPN、代理、加速器。
- 🕵️ **防漏网开关**：可一键显示手机内全部应用，绝不漏掉任何一个。
- ⭐ **收藏置顶**：常驻软件一键收藏，永远排在第一位。
- 🎨 **多套护眼主题**：灰蓝/护眼绿/米黄/夜间，随心切换。
- 🛠 **快捷菜单**：长按即可复制包名、查看信息、卸载应用。
- 🔒 **完全离线**：不联网、无广告、零追踪，纯本地工具。
