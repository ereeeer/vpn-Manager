# 📱 VPN 管理器 (VPN Manager)

因为手机里囤了太多 VPN 和加速器，每次找起来太乱，于是顺手开发了这个轻量级的管理工具。

## ✨ 功能特性
- 🚀 **一键直达**：点击列表直接启动应用。
- 🎯 **智能识别**：通过权限与关键词，精准抓取 VPN、代理、加速器。
- 🕵️ **显示全部应用**：可一键显示手机内全部应用，绝不漏掉任何一个。
- ⭐ **收藏置顶**：常驻软件一键收藏，永远排在第一位。
- 🎨 **多套护眼主题**：灰蓝/护眼绿/米黄/夜间，随心切换。
- 🛠 **快捷菜单**：长按即可复制包名、查看信息、卸载应用。
- 🔒 **完全离线**：不联网、无广告、零追踪，纯本地工具。

*   **[ + ] 手动收编**：开启“显示全部应用”后，若有未被自动识别的 VPN 软件，可直接点击右侧 `[ + ]` 一键收编，永久加入主列表！
*   **❓ 贴心帮助提示**：在“显示全部应用”旁新增帮助按钮，随时查阅收编指南，小白也能轻松上手。
*   **⭐ 收藏置顶**：长按应用即可收藏。被收藏的应用将永久霸占列表第一位，且带有专属小星星。
*   **📦 应用大小展示**：列表直观显示每个软件占用的体积（MB），方便精准清理“吃内存”的闲置软件。

*   **卸载无感自动刷新**：系统广播监听，在手机上卸载软件后返回，列表将瞬间自动更新，无需手动点击刷新。
*   **收藏零抖动**：收藏时的列表逻辑，现在收藏应用会在后台静默登顶，当前页面的浏览位置稳如泰山，再也不会乱跳了。
*   **专属终身编号**：列表最左侧新增固定序号，无论怎么搜索或排序，它的编号都不会变。
*   **磨砂质感 UI**：全面采用半透明磨砂卡片设计，并支持灰蓝、护眼绿、米黄、极夜黑四套主题。
*   **智能反色**：夜间模式下，应用名称、包名和序号会自动反色变白，暗光下也能看得清清楚楚。
